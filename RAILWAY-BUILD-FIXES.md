# Railway Build Fixes - Summary

This document summarizes the fixes applied to resolve Railway build errors and warnings.

## Issues Fixed

### 1. ✅ Missing globals.css File
**Problem:** The file `/app/layout.tsx` referenced `./globals.css` but the file didn't exist.

**Solution:** Created `/app/globals.css` with the Tailwind CSS configuration matching the design system used in `/src/app/globals.css`.

**Files Changed:**
- Created: `app/globals.css`

---

### 2. ✅ TypeScript Compilation Errors
**Problem:** Recharts Tooltip formatters had incorrect TypeScript types, causing build failures.

**Solution:** Updated formatter type definitions to accept `undefined` values for both `value` and `name` parameters.

**Files Changed:**
- `src/components/finance/CashFlowForecast.tsx`
- `src/components/reports/ReportsPage.tsx`

---

### 3. ✅ Invalid Log File
**Problem:** File `build_snapshot_log.tsx` contained invalid TypeScript/JSX syntax and wasn't needed.

**Solution:** Removed the file from the repository.

**Files Changed:**
- Deleted: `build_snapshot_log.tsx`

---

### 4. ✅ Environment Variable Naming
**Problem:** Inconsistent naming between `.env.example` (SMTP_PASS) and actual code (SMTP_PASSWORD).

**Solution:** Updated `.env.example` to use `SMTP_PASSWORD` consistently.

**Files Changed:**
- `.env.example`

---

## Warnings (Informational - No Action Needed)

### Prisma Configuration Deprecation
**Warning:** `package.json#prisma` is deprecated and will be removed in Prisma 7.

**Status:** This is informational. The project currently uses Prisma 6.x which still supports this configuration. Migration to Prisma 7 will require:
- Moving to `prisma.config.ts`
- Updating database connection configuration
- Testing all database operations

**Recommendation:** Plan for Prisma 7 migration in a future sprint. Current setup is functional and supported.

---

### Docker/Nixpacks Warnings

#### SMTP_PASSWORD in ARG/ENV
**Warning:** `SecretsUsedInArgOrEnv: Do not use ARG or ENV instructions for sensitive data (ARG "SMTP_PASSWORD")`

**Status:** This warning is generated by Nixpacks during Docker image build. Railway correctly injects environment variables at runtime, not at build time. The warning is informational.

**Action:** Configure `SMTP_PASSWORD` in Railway's dashboard under Environment Variables. Never commit this value to the repository.

#### NIXPACKS_PATH Undefined
**Warning:** `UndefinedVar: Usage of undefined variable '$NIXPACKS_PATH'`

**Status:** This is an internal Nixpacks variable used during the build process. The warning is harmless and doesn't affect the build.

**Action:** No action needed. This is managed by Nixpacks internally.
